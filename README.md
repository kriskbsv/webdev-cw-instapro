# Instapro

MVP социальной сети для обмена фотографиями.

## Реализованная функциональность

- Интеграция ленты постов с API (вывод реальных постов вместо статичной вёрстки)
- Страница постов отдельного пользователя (переход по клику на имя/аватар автора)
- Добавление поста с текстом и фотографией (загрузка картинки в облако)
- Лайки: постановка и снятие лайка, счётчик лайков
- Доступ по ролям:
  - неавторизованный пользователь видит общую ленту и ленту конкретного пользователя;
  - авторизованный пользователь может лайкать и добавлять посты
- Авторизация и регистрация (сохраняются после перезагрузки страницы)
- Защита от HTML-инъекций: теги, введённые в полях, отображаются как текст
